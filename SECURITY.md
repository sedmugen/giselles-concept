# Security Policy

## Supported Versions

Only the latest release version on the `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The project team takes security issues seriously. If you discover a security vulnerability within **Giselle's Concept**, please follow these steps:

1. **Do not create a public GitHub issue.** Public issues expose vulnerability details before a fix is available.
2. Report the vulnerability privately by contacting the maintainer via GitHub Security Advisories or by emailing `security@sedmugen.dev`.
3. Provide detailed steps to reproduce the issue, including:
   - Specific component or file affected
   - Sample payload or reproduction steps
   - Potential impact of the vulnerability

---

## Response Timeline

* **Acknowledgment**: Within 48 hours of initial report.
* **Assessment & Fix**: Typically within 7 business days depending on severity.
* **Disclosure**: Coordinated public disclosure following release of a patched version.
